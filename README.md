# Muhindo Vicent — Portfolio

Static editorial portfolio with project pages, responsive navigation, and reduced-motion support.

## Local preview

Run `python -m http.server 8000 --directory dist`, then open http://localhost:8000.

Run `python build.py` to regenerate HTML after editing page content. Styles, scripts, fonts, and images are in `dist/`.

## Hosting

Publish the `dist` directory. For Vercel, use the Other framework preset, no build command, and `dist` as the output directory.

## Content status

The hero uses a credited workspace photograph. Personal portrait, certifications, volunteer details, and full project case studies are pending.
